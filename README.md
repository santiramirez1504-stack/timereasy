# ⏱️ TimerEasy

**Timers y versus de regalos para tus directos de TikTok LIVE.**

Este repositorio solo contiene los **instaladores oficiales** de TimerEasy.

## ⬇️ Descargar

👉 **[Descargar TimerEasy para Windows](https://github.com/santiramirez1504-stack/timereasy/releases/latest/download/TimerEasy-Instalador.exe)**

- Requiere Windows 10 u 11 de 64 bits.
- Requiere una **licencia de TimerEasy** (se compra por separado).
- TimerEasy se actualiza solo cuando sale una versión nueva.
